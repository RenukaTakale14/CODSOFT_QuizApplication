# Quiz Application with Timer

A Java-based console quiz application developed as part of the CodSoft Java Development Internship.

## 📌 Project Overview

The Quiz Application presents multiple-choice questions to the user and provides a limited amount of time to answer each question.

The application tracks correct answers and displays the final score and performance summary.

## 🎯 Objective

The objective of this project is to practice:

- Object-Oriented Programming
- Collections
- User input handling
- Timer implementation
- Conditional logic
- Score calculation
- Exception handling

## ✨ Features

- Multiple-choice questions
- Four options for each question
- One question displayed at a time
- 15-second time limit per question
- Answer validation
- Automatic timeout handling
- Score calculation
- Final result screen
- Performance evaluation

## ▶️ How to Run

### Compile

```bash
javac Question.java
javac QuizApplication.java
```

### Run

```bash
java QuizApplication
```

## ⏱️ Quiz Flow

1. A question is displayed.
2. Four multiple-choice options are shown.
3. The user has 15 seconds to answer.
4. The answer is checked.
5. The score is updated for correct answers.
6. The next question is displayed.
7. The final score and percentage are displayed at the end.

## 📚 CodSoft Internship Task

**Task:** Quiz Application with Timer

The task requires storing quiz questions and options, implementing a timer for each question, displaying questions one at a time, accepting answers, calculating the score, and displaying the final result.
